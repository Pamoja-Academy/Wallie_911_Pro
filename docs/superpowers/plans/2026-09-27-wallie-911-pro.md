# Wallie_911_Pro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bou ’n Afrikaanse Next.js-reddingscockpit wat Wallie se 16-dae matric-redding dryf met hard sessie-observeering, foutbank, hibriede vraestel-werkvloei, en Pa-status/waarskuwings.

**Architecture:** Lokale-eerste web-app op skootrekenaar. MissieBord skeduleer 6–7u/dag. ObserveerderSessie vereis kamera + teenwoordigheid, skryf gebeure na plaaslike store, stuur slegs status/alerts na Pa-laag. VraestelWerkvloei + FoutBank dryf retrieval practice. Geen volle video in die wolk.

**Tech Stack:** Next.js (App Router) + Turbopack, TypeScript, React, plaaslike persistence (IndexedDB via `idb` of soortgelyk), `getUserMedia` vir kamera, Afrikaanse UI.

**Spec:** `docs/superpowers/specs/2026-09-27-wallie-911-pro-design.md`

## Global Constraints

- UI-taal: Afrikaans
- Hard-proctor verstek: sessie mag nie begin sonder kamera
- Video: plaaslik; nooit volle sessie-video na wolk as verstek
- Teikens: alle vakke ≥60%; Wisk. Gelett. ≥80%; Engels ≥70%
- Daaglikse kapasiteit: 6–7 gefokusde ure
- YAGNI: geen gamification, geen outo-opstel-gradeerder, geen foon-primêre proctor
- Bronrapport: `C:\Users\User\OneDrive\Documents\Kinders\Wallie Matriekeindeksamen\`
