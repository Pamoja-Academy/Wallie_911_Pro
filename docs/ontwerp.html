Wallie_911_Pro — Ontwerp

1. Produkdoel & sukses

Afrikaanse reddingscockpit vir Graad 12 NSC-finale (vanaf 12 Oktober 2026). Hard sessie-observeering + beproefde leerwetenskap + eksamentegniek.

  • Alle vakke ≥ 60%
  • Wiskundige Geletterdheid ≥ 80%; Engels ≥ 70%
  • ≥90% van 6–7u daaglikse sessies onder hard-proctor
  • Foutlog + hertoets; Pa sien status binne 30s

2. Metodiek (#1 bewyse)

  1. Praktyktoetsing met terugvoer (toe-boek → memo → fout → hertoets)
  2. Verspreide herhaling (spacing oor dae)

Plus: low-hanging fruit eers; eksamentegniek > herlees; foutlog = leerplan.

3. Vakprioriteit

  1. Gasvryheid (27%) — begrip, nie inkram
  2. Afrikaans HT (39%) — moenie vermy
  3. RTT/CAT (37%) — werk insit
  4. Engels (50%, lit 38%) → 70%
  5. Toerisme — lees vrae; klein hoofstukke
  6. Wisk. Gelett. (66%) → 80% daagliks

4. Hard observeerder & privaatheid

Kamera verpligtend op skootrekenaar. Tab-weg / fokus-verlies = waarskuwing. 3× = slot tot Pa-PIN.

Video bly plaaslik in die blaaier. Pa kry status/alerts via die Pa-oortjie (metadata), nie wolk-video-argief nie.

5. Tegnologie (hierdie uitgawe)

Statiese HTML + CSS + JS — oop in eksterne browser. Data in localStorage. Geen Next.js-build nodig vir daaglikse gebruik.
